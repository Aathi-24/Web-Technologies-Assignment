Fundamentals of the World Wide Web

1. Internet Overview

The Internet is a worldwide network that connects millions of computers and other devices. It allows users to share information and communicate with each other.

Computer → Internet → Web Server

Mobile → Internet → Web Server

Some common services provided by the Internet are:

  • World Wide Web
  • Email
  • Online Shopping
  • Video Conferencing
  • Cloud Services

2. Fundamental Computer Network Concepts

A computer network is a group of computers and devices connected together to share data and resources.

Basic Components

  • Node: A device connected to a network.
  • IP Address: An address used to identify a device.
  • Router: Connects different networks.
  • Switch: Connects devices in a network.
  • Protocol: A set of rules used for communication.

3. URL and its Structure

URL stands for Uniform Resource Locator. It is the address used to access a resource on the Internet.

Example:

https://www.example.com/index.html

The main parts of a URL are:

  • https: Protocol
  • www: Subdomain
  • example.com: Domain name
  • /index.html: Path of the webpage

4. Domain Name

A domain name is the human-readable name of a website. It is easier to remember than an IP address.

Example:

www.google.com

In this example:

  • www - Subdomain
  • google - Website name
  • .com - Top Level Domain

Examples of Domain Extensions

  • .com - Commercial websites
  • .org - Organizations
  • .edu - Educational institutions
  • .gov - Government websites
  • .in - India

5. Web Browsers and Web Servers

Web Browser

A web browser is software used to access and display websites on the Internet.

Examples:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

Web Server

A web server is a computer or software that stores website files and sends them to the user's browser when requested.

Examples:

  • Apache
  • Nginx
  • Microsoft IIS

6. Working Principle of a Website

A website works using communication between the user's browser and a web server.

Steps:

  1. User enters a website URL.
  2. Browser sends a request to the Internet.
  3. DNS finds the IP address of the website.
  4. The request reaches the web server.
  5. The server processes the request.
  6. The server sends the webpage back to the browser.
  7. The browser displays the webpage.
